About

I'm John Afunwi, a computer science student who learns best by building. I'm working toward IT certifications and putting together technical projects for my portfolio, including a SOC analyst home lab and a mobile password tracker app. This site is my ITIS 3135 coursework, and I'm adding to it as I go.

In this course I'm using VS Code as my editor, with Emmet to write HTML faster. I keep my work in version control with GitHub and publish it through GitHub Pages and the university web server. Accumulus checks my pages as I build them.

Over the semester I will build these sites:

  • A personal home page
  • A course site
  • A design firm site
  • A CRAPpy page
  • A whimsical product company site
  • A client project
